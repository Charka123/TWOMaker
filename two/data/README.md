# Basemap data

`ne_110m_land.geojson` is Natural Earth 1:110m land, version 5.1.2.
It is bundled unchanged so image generation needs no network connection.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_land.geojson
- License: public domain, https://www.naturalearthdata.com/about/terms-of-use/

Small islands and coastlines are simplified at this scale.
